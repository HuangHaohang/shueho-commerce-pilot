# Layout System

## App Shell

桌面端固定为两栏结构：

```text
+----------------------------+--------------------------------------+
| Sidebar 258px              | Workspace                            |
|                            |                                      |
| Top brand + actions        | Top centered mode switch             |
| Primary nav                |                                      |
|                            | Centered workbench                   |
|                            |                                      |
| Account/workspace footer   | Agent output / task context          |
+----------------------------+--------------------------------------+
```

## Sidebar

| 属性 | 值 |
|---|---:|
| 宽度 | `258px` |
| 背景 | `--cp-sidebar` |
| 右边框 | `1px solid --cp-border` |
| 顶部 padding | `12px` |
| 菜单行高 | `36px` |
| 菜单圆角 | `8px` |
| 图标尺寸 | `18px` |
| 菜单文字 | `14px / 1.4 / 400` |
| active 背景 | `--cp-surface-hover` |

侧栏用于：

- 产品名或工作区名。
- 新任务入口。
- 市场调研、创作空间、资料库等一级能力。
- 更多入口，通过侧栏右侧弹出菜单收纳已安排和插件，不占用侧栏纵向空间。
- 底部账户区或组织区。

侧栏不用于：

- 大面积统计卡。
- 彩色营销 banner。
- 多层深嵌套菜单。
- 外部系统 credential 或 token 展示。

## Workspace

主工作区使用白色或近白背景，不增加装饰图形。工作台内容以 viewport 剩余区域居中：

| 属性 | 值 |
|---|---:|
| 顶部模式切换区域高度 | `56px` |
| 中央内容最大宽度 | `820px` |
| 可读文本最大宽度 | `760px` |
| 桌面左右安全边距 | `32px` |
| 移动左右安全边距 | `16px` |

## Mode Switch

顶部模式切换为 pill segmented control：

- 外层高度 `36px`。
- 外层背景 `--cp-bg-subtle`。
- 单项最小宽度 `98px`。
- 当前项白底、轻微边框或阴影。
- 文案短，最多 4 个汉字或 1 个短英文词。

第一阶段建议保留两个模式：

- `聊天`: 常规问答、解释、查询。
- `工作`: 结构化电商任务、审批、执行、读回。

## Work Composer

中央 composer 是首屏核心组件：

| 属性 | 值 |
|---|---:|
| 最大宽度 | `820px` |
| 最小高度 | `128px` |
| 圆角 | `24px` |
| 背景 | `--cp-surface` |
| 边框 | `1px solid --cp-border` |
| 阴影 | `--cp-shadow-composer` |
| 内边距 | `18px 20px` |
| placeholder | `14px / --cp-text-faint` |

composer 内部稳定区域：

- 顶部输入区：支持多行输入，输入增长不得让整页跳动失控。
- 左下工具区：附件、上下文、项目、工具入口。
- 右下动作区：提交、停止、继续。
- 登录后的右下配置区：文本模型、推理强度、语音和提交；不显示速度设置。
- 下方 context strip：项目选择、店铺选择、数据范围选择。

不可做成：

- 彩色搜索框。
- 巨大 marketing CTA。
- 带复杂背景图或玻璃拟态。
- 嵌套多个卡片的操作区。

## Agent Output

任务开始后，workspace 从首屏居中态过渡到会话工作态：

- 输出区域最大宽度保持 `820px`。
- 用户消息右对齐但不使用高饱和彩色气泡。
- agent 消息左对齐或全宽，内容区使用自然文本和结构化对象块。
- 工具调用、审批、读回证据以轻量边框块展示。
- 事件流默认折叠到可扫描层级，但关键审批、错误、读回失败必须展开。
- 首次提交后首屏 composer 过渡为会话布局：滚动正文、右侧可选输出面板、底部固定追问 composer。
- 工具和命令活动默认折叠为单行摘要，由用户展开查看明细，不能随事件数量无限占用正文高度。
- 会话 shell 固定为 `100dvh` 且禁止页面级滚动；只有中间对话区域允许纵向滚动。
- 会话正文从顶栏下方紧凑开始，不保留大面积顶部空白；右侧输出面板与正文顶部对齐。
- 对话区只在滚动位置接近底部时跟随 SSE；用户上翻后保持当前阅读位置，并用悬浮回到底部按钮恢复跟随。
- 桌面长对话可在中间滚动区左侧显示时间线 minimap；它是对话容器的覆盖层，不占用正文列宽，不参与页面布局，也不能创建第二个页面级滚动上下文。

## Compliance Footer

未登录首页主工作区底部固定保留一行低对比合规提示：

- 明确用户正在与 AI 交互。
- 链接到使用条款、隐私政策和 AI 使用说明三个真实路由。
- 位于主工作区正常文档流底部，不使用浮层，不遮挡 composer。
- 桌面端单行优先，窄屏允许自然换行并保持居中。
- 字号 `11px`，颜色使用 `--cp-text-faint`，链接通过下划线而非主题色识别。

法律文件页面使用独立窄栏文档布局：顶部返回动作、最大正文宽度 `760px`、无卡片容器、章节间距明确，并在底部提供三份文件的交叉导航。

## Commerce Panels

订单、商品、库存、售后等对象预览可以使用 item/card，但必须满足：

- 圆角 `8px`。
- 不嵌套卡片。
- 标题区包含对象类型、外部系统、业务编号。
- 状态使用小型 badge 或文本，不使用大面积彩色块。
- 主动作放右上或底部工具行，不把危险动作混在普通链接里。

## Mobile

移动端断点建议：

- `< 768px`: 侧栏折叠为 drawer；workspace 全宽。
- `768px - 1023px`: 可显示窄侧栏或折叠侧栏，视任务密度决定。
- `>= 1024px`: 固定侧栏。

移动端规则：

- 不允许横向滚动。
- composer 左右边距 `16px`。
- mode switch 仍居中，但宽度自适应内容。
- 长表格必须转为分组列表或横向容器，不能撑破 viewport。
- 审批动作固定在可见区域底部时，不能遮挡正文；需要预留底部 padding。

## Density

本项目不是传统后台，但电商操作也不能过度空泛：

- 首页和会话工作台保持宽松。
- 列表、审批队列、对象详情保持可扫描密度。
- 重复行高建议 `40px - 52px`。
- 表格只用于大量结构化对比；少量对象优先列表或对象预览。

## Layout Checks

前端完成后必须至少检查：

- `1440x900` 桌面。
- `1280x720` 窄高比桌面。
- `390x844` 移动。
- `768x1024` 平板。

检查项：

- 无横向滚动。
- 文本不重叠、不截断关键业务编号。
- composer 和 mode switch 不互相遮挡。
- sidebar footer 不盖住菜单。
- event stream 长内容不会挤破布局。
